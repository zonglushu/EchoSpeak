## 📋 归档标准

文档会在以下情况下被归档：

1. **问题已解决**：文档记录的问题已完全修复
2. **内容已过时**：技术方案已更新，文档不再适用
3. **已被替代**：新文档已覆盖相同内容
4. **仅供参考**：虽然过时，但保留历史价值
